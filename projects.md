# Projects

## 1. Academic Path Intelligence
- **Tech Stack:** Vite, React 18, TypeScript, Tailwind CSS 3, lucide-react
- **Description:** Learning-roadmap builder that maps the skills a student picks to their prerequisites and lays out a personalised path, running entirely in the browser.
- **Code:** https://github.com/adityatiwari9t8/academic-path-intelligence

## 2. Expense Insight Pro
- **Tech Stack:** Vite, React 18, TypeScript, Tailwind CSS 3, Recharts, lucide-react
- **Description:** In-browser expense tracker showing balance trends and 30-day forecasts with no backend required.
- **Code:** https://github.com/adityatiwari9t8/expense-insight-pro

## 3. Sudoku Algorithm Visualizer
- **Tech Stack:** Vite, React 18, TypeScript, Tailwind CSS 3, lucide-react
- **Description:** Interactive browser tool that compares four search algorithms solving Sudoku puzzles with real-time visualization and performance metrics.
- **Code:** https://github.com/adityatiwari9t8/sudoku-algorithm-visualizer
